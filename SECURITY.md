# Security policy

## Intended use

CyberShield is an educational, defensive monitoring demo. Use only with simulated events or systems you are authorized to administer.

## Reporting an issue

For this coursework project, document the issue and the steps needed to reproduce it in a private report to the repository maintainer. Do not include real credentials, personal information, or production logs.

## Important limitations

- The default API keys are for local demos only and must be changed before any shared deployment.
- Events and alerts are stored in memory and are lost on restart.
- Use HTTPS/TLS and a secret manager before exposing the service beyond localhost.
- This project is not a production authentication service or a full SIEM.
